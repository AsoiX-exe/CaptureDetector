# Contributing to CaptureDetector

Thanks for taking the time to help out — contributions of every size are welcome:
bug reports, fixes, new platform support, docs or ideas.

## How to contribute
- **Found a bug?** Open an issue with your OS, what you did and what happened.
- **Have a fix or feature?** Fork the repo, make a branch, and open a pull request against `master`.
- Keep the style close to what's already there — plain C, no extra dependencies, builds cleanly
  with gcc / MSVC / CMake.
- One focused change per PR makes review easier.

## Building
See the build instructions in the [README](README.md).

Not sure about something? Open an issue and ask.
