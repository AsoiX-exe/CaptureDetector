# TinyCC
* 1. Run setup_tcc.bat as Admin to install TCC/Win32 API
* 2. Run build_tcc.bat, compiled executable can be found in build/ folder

# Windows (MSVC)
* Requirements: MSVC2022/2026
* 1. Run build_msvc.bat

# Linux
* 1. chmod a+x build.sh
* 2. Run ./build.sh
* 3. Compiled executable can be found in build/

# macOS
* 1. chmod a+x build.sh
* 2. Run ./build.sh
* 3. Compiled executable can be found in build/
